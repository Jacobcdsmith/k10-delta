# Display Control Skill

Controls the 240x320 IPS display on the K10 device.

## Capabilities

- Display text at specified coordinates
- Clear the display
- Set screen brightness
- Display preview image from URL

## Usage

Call via MCP tools:
- `display.show_text` - Show text on screen
- `display.clear` - Clear screen
- `display.set_brightness` - Adjust backlight
